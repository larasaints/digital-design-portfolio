# Glow & Grace — E-Commerce Checkout Motion Graphic

A beauty and skincare e-commerce motion graphic created to showcase an interactive shopping experience through product-focused visual presentation, animated UI transitions, typography, and promotional messaging.

## Project Details

| Category | Details |
| :--- | :--- |
| **Project Type** | E-Commerce / Beauty Motion Graphic |
| **Role** | Digital Designer / Motion Designer |
| **Tools** | Canva, CapCut |
| **Deliverable** | 10-page animated promotional design |
| **Focus** | Product presentation, UI/UX animation simulation, transitions, visual hierarchy, CTA placement |

## My Role

I created the visual direction and developed the complete e-commerce presentation, including:

* Layout and mobile UI mockup composition
* Typography and text hierarchy
* Interactive "Add to Cart" click animation arrangement
* Skincare/Cosmetics product pop-up sequencing
* Promotional tagline design and placement
* Consistent lavender/gold visual styling across all frames
* Animated basket-fill transitions between sections
* Motion timing and pacing for social media format
* Final video editing and sound-effect timing

## Motion Design

The static UI mockup elements were developed into a dynamic motion graphic using animated transitions and carefully timed visual elements. The motion treatment was designed to:

* Guide viewers through a stylized checkout interaction
* Simulate interactive UI button clicks ("Add to Cart")
* Animate products lifting dynamically into a physics-based retail basket
* Designed to maintain attention while keeping information clean and elegant
* Lead viewers toward the final brand slogan promotional screen

**UI Mockup & Layout → Canva Element Design → Click & Drop Animation → Timing & Pacing in CapCut → Final Motion Graphic**
