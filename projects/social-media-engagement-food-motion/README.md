# "What is Your Favorite Pasta?" — Sequential Path Motion Graphic

A social media promotional motion graphic showcasing a variety of gourmet pasta dishes through a multi-point layout progression, framed by bold, static typography.

## Project Details

| Category | Details |
| :--- | :--- |
| **Project Type** | Food Promotion & Social Media Animation |
| **Role** | Digital Designer / Motion Designer |
| **Tools** | Canva, CapCut |
| **Deliverable** | 8-page sequential layout animation |
| **Focus** | Multi-point asset tracking, typographic framing, pattern synchronization, layout progression |

## My Role

I established the visual presentation structure and developed the multi-point animation sequence, including:

* Designing a custom, repeating yellow vector noodle line-art background pattern
* Calculating and mapping the sequential layout coordinates (Point A → B → C → D → E → F) for 8 distinct pasta plate assets
* Engineering the split foreground typography ("What is your Fav rite Pasta?") to serve as a static window frame
* Controlling asset layering and canvas positioning so dishes step smoothly across the screen on every beat
* Tuning frame-by-frame pacing to optimize dish visibility as they reach key layout markers
* Splicing and exporting the multi-page Canva canvas into a synchronized high-definition video loop

## Motion Design & Layout Strategy

The project utilizes a distinct path-based positioning effect built to capture attention through structured visual steps:

* **Static Typographic Window:** The prominent green typography remains anchored in place, instantly posing a question to the viewer while keeping the center screen open for product focus.
* **Multi-Point Asset Progression:** Instead of a simple linear scroll, the plate elements jump sequentially through precise spatial positions, creating a rhythmic layout progression across the frames.
* **Synchronized Step Changes:** The stylized noodle illustration backdrop moves in coordination with the plate steps, maintaining layout harmony across the 8-page sequence.
